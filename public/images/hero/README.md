# Images du hero (vitrine produit)

Déposez ici les **3 photos produit** de la page d'accueil — elles remplacent
automatiquement les placeholders au déploiement suivant, sans toucher au code.

| Fichier attendu   | Produit affiché          |
| ----------------- | ------------------------ |
| `verre.jpg`       | Garde-corps en verre     |
| `aluminium.jpg`   | Garde-corps en aluminium |
| `inox.jpg`        | Garde-corps en inox      |

Extensions acceptées : `.webp` (recommandé), `.jpg`, `.jpeg`, `.png`, `.avif`
— la première trouvée est utilisée.

## Recommandations

- **Format 4:3 paysage**, minimum **1200 × 900 px** (l'image est affichée en
  grand puis recadrée en `object-cover`).
- Poids conseillé **< 300 Ko** (compressez en WebP qualité ~80).
- Choisissez des photos **en situation** (terrasse, piscine, escalier) où le
  garde-corps est net et bien visible — c'est la première chose que voit le
  visiteur.
- Les mêmes images servent aux vignettes : cadrez avec le produit au centre.
